## Prečo Hi.Events?

Väčšina platforiem na predaj vstupeniek si berie poplatok z každej vstupenky a ponecháva si údaje o vašich zákazníkoch. **Hi.Events je open-source
alternatíva k Eventbrite, Tickettailor, Dice.fm a ďalším platformám na predaj vstupeniek**, ktorá vám dáva plnú kontrolu nad
vašou značkou, procesom objednávky a dátami.

Dôverujú mu tisíce organizátorov podujatí po celom svete — od promotérov nočného života a festivalov po kluby, komunitné skupiny
a organizátorov konferencií. Prevádzkujte ho sami alebo to nechajte na nás v Hi.Events Cloud.

<br>

## Funkcie

**📅 Podujatia**
- Jednorazové aj opakujúce sa podujatia s vlastnými cenami, kapacitou a časmi pre každý termín
- Duplikovanie podujatia jedným kliknutím
- Uložené miesta konania a online podujatia
- Návrhár domovskej stránky podujatia a stránky organizátorov vo vašej značke
- Stránky s line-upom a programom

**🎟️ Vstupenky a produkty**
- Platené, bezplatné, darcovské a cenovo odstupňované vstupenky
- Rezervácia sedadiel <sup>Enterprise</sup>
- Doplnky a merchandising
- Skryté vstupenky odomykané promo kódmi
- Limity na objednávku a naplánované obdobia predaja
- Zdieľaná kapacita a automatické čakacie zoznamy

**🛒 Predaj**
- Prispôsobiteľné vloženie na váš web: widgety vstupeniek, tlačidlá, zoznamy podujatí, line-upy a programy
- Promo kódy a zľavy
- Sledovacie odkazy pre promotérov a partnerov
- Vlastné registračné otázky
- Marketingový súhlas pri objednávke
- Sledovanie cez Meta, TikTok, Google Analytics a Tag Manager

**💳 Platby**
- Výplaty na váš vlastný účet Stripe
- Dane a poplatky, zahrnuté v cene alebo pripočítané pri objednávke
- Fakturácia a offline platby
- Úplné aj čiastočné vrátenie peňazí

**🚪 Účastníci a vstup**
- Pokladňa na predaj pri vstupe <sup>Enterprise</sup>
- Odbavenie fotoaparátom telefónu alebo USB skenerom
- Zdieľateľné zoznamy odbavení s počtami v reálnom čase
- Správy účastníkom a vlastné e-mailové šablóny
- PDF vstupenky vo vašej značke
- Ručne pridaní účastníci
- Prehľady predaja, daní a promo kódov

### Docker

```bash
git clone https://github.com/HiEventsDev/hi.events.git
cd hi.events/docker/all-in-one

cp .env.example .env

# Generate keys (Linux/macOS)
echo "APP_KEY=base64:$(openssl rand -base64 32)" >> .env
echo "JWT_SECRET=$(openssl rand -base64 32)" >> .env

docker compose up -d
```

> [!TIP]
> **Používatelia Windows:** Postup generovania kľúčov nájdete v `./docker/all-in-one/README.md`.

Otvorte `http://localhost:8123` a vytvorte si účet.
