## 왜 Hi.Events인가요?

대부분의 티켓 판매 플랫폼은 티켓마다 수수료를 떼어 가고 고객 데이터를 가져갑니다. **Hi.Events는 Eventbrite, Tickettailor, Dice.fm 등
티켓 판매 플랫폼을 대체하는 오픈소스 솔루션**으로, 브랜딩과 결제, 데이터를
완벽하게 직접 관리할 수 있습니다.

나이트라이프 프로모터와 페스티벌부터 공연장, 커뮤니티 단체,
컨퍼런스 주최자까지 전 세계 수천 명의 이벤트 주최자가 신뢰합니다. 직접 운영하거나, Hi.Events Cloud에서 저희에게 맡기세요.

<br>

## 주요 기능

**📅 이벤트**
- 단일 및 반복 이벤트, 날짜별 가격·수용 인원·시간 설정
- 클릭 한 번으로 이벤트 복제
- 저장된 장소 및 온라인 이벤트
- 이벤트 홈페이지 디자이너 및 브랜드 주최자 페이지
- 라인업 및 일정표 페이지

**🎟️ 티켓 및 상품**
- 유료, 무료, 기부 및 등급별 티켓
- 지정 좌석 <sup>Enterprise</sup>
- 추가 옵션 및 굿즈
- 프로모션 코드로 공개되는 숨김 티켓
- 주문당 구매 한도 및 판매 기간 예약
- 공유 수용 인원 및 자동 대기자 명단

**🛒 판매**
- 내 사이트에 맞춤형 임베드: 티켓 위젯, 버튼, 이벤트 목록, 라인업, 일정표
- 프로모션 코드 및 할인
- 프로모터 및 제휴 파트너용 추적 링크
- 맞춤 등록 질문
- 결제 시 마케팅 수신 동의
- Meta, TikTok, Google Analytics, Tag Manager 추적

**💳 결제**
- 내 Stripe 계정으로 직접 정산
- 세금 및 수수료, 가격에 포함하거나 결제 시 추가
- 인보이스 발행 및 오프라인 결제
- 전액 및 부분 환불

**🚪 참석자 및 현장 입장**
- 현장 판매용 박스 오피스 <sup>Enterprise</sup>
- 휴대폰 카메라 또는 USB 스캐너로 체크인
- 실시간 인원이 표시되는 공유용 체크인 목록
- 참석자 메시지 및 맞춤 이메일 템플릿
- 브랜드 PDF 티켓
- 참석자 수동 추가
- 판매, 세금, 프로모션 코드 보고서

### Docker

```bash
git clone https://github.com/HiEventsDev/hi.events.git
cd hi.events/docker/all-in-one

cp .env.example .env

# Generate keys (Linux/macOS)
echo "APP_KEY=base64:$(openssl rand -base64 32)" >> .env
echo "JWT_SECRET=$(openssl rand -base64 32)" >> .env

docker compose up -d
```

> [!TIP]
> **Windows 사용자:** 키 생성 방법은 `./docker/all-in-one/README.md`를 참고하세요.

`http://localhost:8123`을 열고 계정을 만드세요.

## 라이선스

Hi.Events는 **AGPL-3.0 및 추가 조항**에 따라 라이선스가 부여됩니다. 추가 조항에 따라 소프트웨어가 생성하는 페이지와 이메일에 "Powered by Hi.Events"
표기를 유지해야 합니다. 정확한 문구는 [LICENCE](LICENCE)를 참고하세요.

지정 좌석과 박스 오피스는 [Hi.Events Enterprise Licence](backend/ee/LICENCE)가 적용되며, 프로덕션 환경에서 사용하려면
라이선스가 필요합니다.

표기를 제거하거나 화이트 라벨 배포에 맞는 조건이 필요하다면 **상업용 라이선스를 이용할 수 있습니다**.
