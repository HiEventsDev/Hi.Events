## Miksi Hi.Events?

Useimmat lipunmyyntialustat perivät maksun jokaisesta lipusta ja pitävät asiakastietosi itsellään. **Hi.Events on avoimen lähdekoodin
vaihtoehto Eventbritelle, Tickettailorille, Dice.fm:lle ja muille lipunmyyntialustoille**, ja sen avulla hallitset täysin
brändiäsi, kassaprosessiasi ja dataasi.

Tuhannet tapahtumanjärjestäjät ympäri maailmaa luottavat siihen – yöelämän promoottoreista ja festivaaleista tapahtumapaikkoihin, yhteisöihin
ja konferenssien järjestäjiin. Ylläpidä sitä itse tai anna meidän hoitaa se puolestasi Hi.Events Cloudissa.

### Docker

```bash
git clone https://github.com/HiEventsDev/hi.events.git
cd hi.events/docker/all-in-one

cp .env.example .env

# Generate keys (Linux/macOS)
echo "APP_KEY=base64:$(openssl rand -base64 32)" >> .env
echo "JWT_SECRET=$(openssl rand -base64 32)" >> .env

docker compose up -d
```

> [!TIP]
> **Windows-käyttäjät:** Ohjeet avainten luomiseen löytyvät tiedostosta `./docker/all-in-one/README.md`.

Avaa `http://localhost:8123` ja luo tilisi.
