## Proč Hi.Events?

Většina platforem pro prodej vstupenek si účtuje poplatek z každé vstupenky a ponechává si data vašich zákazníků. **Hi.Events
je open-source alternativa k Eventbrite, Tickettailor, Dice.fm a dalším platformám pro prodej vstupenek**, která vám dává
plnou kontrolu nad značkou, pokladnou a daty.

Důvěřují nám tisíce organizátorů po celém světě — od promotérů nočního života a festivalů po místa konání, komunitní
skupiny a pořadatele konferencí. Provozujte ho sami, nebo to nechte na nás v Hi.Events Cloud.

<br>

## Funkce

**📅 Události**
- Jednorázové i opakované události s cenami, kapacitou a časy pro jednotlivé termíny
- Duplikace události jedním kliknutím
- Uložená místa konání a online události
- Návrhář domovské stránky události a brandované stránky organizátora
- Stránky s programem a harmonogramem

**🎟️ Vstupenky a produkty**
- Placené, bezplatné, dobrovolné a víceúrovňové vstupenky
- Místa k sezení <sup>Enterprise</sup>
- Doplňky a merch
- Skryté vstupenky odemykané promo kódy
- Limity na objednávku a plánovaná období prodeje
- Sdílená kapacita a automatické pořadníky

**🛒 Prodej**
- Přizpůsobitelné vložené prvky pro váš web: widgety vstupenek, tlačítka, seznamy událostí, programy a harmonogramy
- Promo kódy a slevy
- Sledovací odkazy pro promotéry a affiliate partnery
- Vlastní registrační otázky
- Marketingový souhlas v pokladně
- Měření přes Meta, TikTok, Google Analytics a Tag Manager

**💳 Platby**
- Výplaty na váš vlastní účet Stripe
- Daně a poplatky, zahrnuté v ceně nebo připočtené v pokladně
- Fakturace a offline platby
- Plné i částečné refundace

**🚪 Účastníci a vstup**
- Pokladna pro prodej na místě <sup>Enterprise</sup>
- Odbavení kamerou telefonu nebo USB skenerem
- Sdílitelné seznamy odbavení s živými počty
- Zprávy účastníkům a vlastní e-mailové šablony
- Brandované PDF vstupenky
- Ručně přidaní účastníci
- Reporty prodejů, daní a promo kódů

### Docker

```bash
git clone https://github.com/HiEventsDev/hi.events.git
cd hi.events/docker/all-in-one

cp .env.example .env

# Vygenerujte klíče (Linux/macOS)
echo "APP_KEY=base64:$(openssl rand -base64 32)" >> .env
echo "JWT_SECRET=$(openssl rand -base64 32)" >> .env

docker compose up -d
```

> [!TIP]
> **Uživatelé Windows:** Pokyny ke generování klíčů najdete v `./docker/all-in-one/README.md`.

Otevřete `http://localhost:8123` a vytvořte si účet.

📖 [Kompletní návod k instalaci](https://hi.events/docs/getting-started?utm_source=gh-readme)
