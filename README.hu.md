## Miért a Hi.Events?

A legtöbb jegyértékesítő platform minden jegy után díjat számol fel, és megtartja az Ön vásárlói adatait. **A Hi.Events nyílt forráskódú
alternatíva az Eventbrite, a Tickettailor, a Dice.fm és más jegyértékesítő platformok helyett**, amellyel teljes kontrollt kap
a márkamegjelenés, a vásárlási folyamat és az adatok felett.

Világszerte több ezer eseményszervező bízik benne – éjszakai promóterektől és fesztiváloktól a helyszíneken és közösségi csoportokon át
a konferenciaszervezőkig. Üzemeltesse saját maga, vagy bízza ránk a Hi.Events Cloudban.

## Funkciók

**📅 Események**
- Egyszeri és ismétlődő események, időpontonkénti árakkal, kapacitással és időbeosztással
- Esemény duplikálása egy kattintással
- Mentett helyszínek és online események
- Esemény-kezdőlap szerkesztő és saját márkás szervezői oldalak
- Line-up és program oldalak

**🎟️ Jegyek és termékek**
- Fizetős, ingyenes, adomány alapú és sávos jegyek
- Helyfoglalás <sup>Enterprise</sup>
- Kiegészítők és merchandise termékek
- Promóciós kóddal feloldható rejtett jegyek
- Rendelésenkénti limitek és ütemezett értékesítési időszakok
- Közös kapacitás és automatikus várólisták

**🛒 Értékesítés**
- Testreszabható beágyazások saját weboldalra: jegywidgetek, gombok, eseménylisták, line-upok és programok
- Promóciós kódok és kedvezmények
- Követő linkek promótereknek és partnereknek
- Egyedi regisztrációs kérdések
- Marketing-hozzájárulás a vásárláskor
- Meta, TikTok, Google Analytics és Tag Manager követés

**💳 Fizetések**
- Kifizetések közvetlenül a saját Stripe-fiókjába
- Adók és díjak, az árban foglalva vagy a vásárláskor hozzáadva
- Számlázás és offline fizetések
- Teljes és részleges visszatérítések

**🚪 Résztvevők és beléptetés**
- Pénztár helyszíni jegyeladáshoz <sup>Enterprise</sup>
- Beléptetés telefonkamerával vagy USB-szkennerrel
- Megosztható beléptetési listák élő számlálással
- Üzenetküldés a résztvevőknek és egyedi e-mail-sablonok
- Saját márkás PDF-jegyek
- Kézzel hozzáadott résztvevők
- Értékesítési, adó- és promóciós kód riportok

### Docker

```bash
git clone https://github.com/HiEventsDev/hi.events.git
cd hi.events/docker/all-in-one

cp .env.example .env

# Generate keys (Linux/macOS)
echo "APP_KEY=base64:$(openssl rand -base64 32)" >> .env
echo "JWT_SECRET=$(openssl rand -base64 32)" >> .env

docker compose up -d
```

> [!TIP]
> **Windows-felhasználók:** A kulcsok generálásának lépéseit a `./docker/all-in-one/README.md` fájlban találja.

Nyissa meg a `http://localhost:8123` címet, és hozza létre fiókját.

📖 [Teljes telepítési útmutató](https://hi.events/docs/getting-started?utm_source=gh-readme)
