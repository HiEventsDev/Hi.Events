# Tasks

Each group is releasable on its own and lands its own backend tests, E2E specs, translations and docs. Run `pint --test`, the Unit suite and `npx tsc --noEmit` at the end of every group; run the Feature suite, `php artisan api-reference:export` and the api-smoke-test skill for every group that adds or changes an endpoint.

**E2E coverage rule.** Every scenario in the three specs is covered by a Playwright spec, listed in each group's "E2E" tasks. The only scenarios left to backend tests alone are those with no user-visible surface to drive, and they are named in task 8.4. E2E specs arrange data through the API or factory, drive the flow under test through the UI with page objects, read emails through Mailpit, and assert on page content. Specs that need a real card payment use the existing Stripe test-card helpers and skip themselves when the stack has no Stripe test keys.
